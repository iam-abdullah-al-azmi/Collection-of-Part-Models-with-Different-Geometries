# Collection of Part Models with Different Geometries

## Summary

This project brings together six standalone SolidWorks part models, each with a different geometry. They include a hammer head with a forked claw, a three-arm bracket with a central hub, a cylindrical housing with mounting lugs, a bell crank, and two thin-walled shells. Instead of keeping each part as a separate project, I grouped them into this single collection so that they can be browsed, compared, and extended in one place.

Every model is a single part file that was developed as a computational model in SolidWorks, and each one explores a different combination of shapes, such as curves, bores, pockets, lugs, and thin walls. The models are concept prototypes, not finished engineering designs. Where I could not identify the exact real-world part, the model is named after its geometry instead of a guessed function. The overview below shows the isometric view of each model, and the table that follows it links to the detailed documentation of every model.
